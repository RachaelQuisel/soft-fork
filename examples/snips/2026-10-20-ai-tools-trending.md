### Snip 1: Visa, BILL and Billtrust: a trusted agent pays approved invoices, live
- Source: Billtrust (Business Wire release)
- Episode/article: "AI Agents for Payments: Visa, BILL & Billtrust Partnership"
- Date: 2026-10-20
- Link: https://www.billtrust.com/news/news-visa-bill-billtrust-launch-ai-agents-for-payments
- Summary: Visa, BILL and Billtrust launched what they call the first live pilot letting trusted AI agents initiate and complete approved buyer invoice payments end to end through supplier portals, and it is already processing real transactions. The BILL Payment Agent registers through Visa's Trusted Agent Protocol and Agentic Directory, uses tokenized credentials instead of shared portal logins, and follows controls tied to the buyer's approved payment instructions. Billtrust's side recognizes and authenticates the agent, which can satisfy the site protections historically provided by CAPTCHA and other bot blocking, without an extra agent login. The release is explicit on the key limit: the agent is not making payment decisions, it only executes payments the buyer already approved, on a purpose-built path tied to the specific invoice, with visibility into authorization and completion. BILL serves nearly 500,000 businesses.
- Loop/workflow angle: a complete money loop with the decision kept human. Approval first, then a named agent, tokenized credentials, an amount and purpose bound to one invoice, and a visible record. This is today's workshop pick.

### Snip 2: Raleigh cuts IT support costs by 66 percent with ServiceNow agents
- Source: Intelligent CIO North America
- Episode/article: "Raleigh cuts IT support costs by 66% as ServiceNow AI agents take over government workloads"
- Date: 2026-10-20
- Link: https://www.intelligentcio.com/north-america/2026/10/20/raleigh-cuts-it-support-costs-by-66-as-servicenow-ai-agents-take-over-government-workloads/
- Summary: Raleigh, North Carolina, reported a 66 percent reduction in service desk costs after deploying ServiceNow autonomous agents, resolving nearly half of IT support requests without human intervention. The city supports about 4,400 municipal employees with a help desk team of just four people, and handles roughly 300,000 resident service calls a year. Its first agent, Ral-E, guides and routes and reached a reported 98 percent deflection rate; the newer Alli is an autonomous first-line specialist that resolves complete workflows using historical incidents and documented procedures, with humans supervising and maintaining the knowledge base. The city has automated more than 20 workflows, reports 98 percent of AI incident summaries accepted without modification and 98 percent of tickets routed correctly, and aims to lift autonomous resolution from nearly 50 percent toward 85 percent. The article notes the cost base, period, and licensing costs were not disclosed, so the 66 percent is a reported figure, not an audited one.
- Loop/workflow angle: end-to-end resolution, not answers. The foundation was a decade of documented procedures and service records; the agent works because the playbook was written down first.

- Link: https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-tuesday-october-20-2026/

### Snip 4: Microsoft adds controls that can restrict or shut down risky agents
- Source: The Neuron (reporting GeekWire)
- Episode/article: "Everything That Happened in AI Today Tuesday, October 20"
- Date: 2026-10-20
- Link: https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-tuesday-october-20-2026/
- Summary: In the same October 20 digest, Microsoft introduced new security controls in Microsoft 365 E7 and Project Perception that assess individual agents for risk. Administrators can restrict an agent from making changes, require human approval before it acts, or shut it down. ### Snip 7: Albato: the agent as a step inside a real automation
- Source: Albato
- Episode/article: "Best AI Agent Platforms for No-Code Automation (2026)"
- Date: 2026-10-20 (updated within the last day on the October 20 check)
- Link: https://albato.com/blog/publications/best-ai-agent-platforms
- Summary: This platform comparison, updated for October 2026, puts Albato first on a specific argument: its agent is a step inside a working automation, not a standalone bot you then wire into your stack. A trigger starts the flow, and an AI Agent step reads data from earlier steps and decides which action to run next across more than 1,000 apps and about 5,000 actions exposed as tools. ### Snip 8: AGENTS.md vs CLAUDE.md: what each coding agent actually reads
- Source: Import Static
- Episode/article: "AGENTS.md vs CLAUDE.md in Claude Code, Codex and Copilot"
- Date: 2026-10-19 (documentation checked October 19, 2026)
- Link: https://importstatic.com/ai/agents-md-vs-claude-md
- Summary: This explainer, built from each tool's documentation as of October 19, maps which instruction files each agent reads. Claude Code reads CLAUDE.md first and only falls back to AGENTS.md if no CLAUDE.md exists on the path up; Codex reads AGENTS.override.md, then AGENTS.md, concatenating from the git root down and stopping at 32 KiB by default; Copilot, Cursor, and Gemini CLI each have their own order and their own file names. The practical trap is plain: the same folder can give different agents different instructions, and an owner who edits the wrong file changes nothing.
- Loop/workflow angle: your standing instructions are a file, and files have a load order. Knowing which file your agent actually reads is the difference between a rule that runs and a rule that sits in a drawer.

### Workshop pick
Snip 1, "AI Agents for Payments: Visa, BILL & Billtrust Partnership" (Billtrust / Business Wire, 2026-10-20). This is the richest end-to-end workflow in the batch for small business owners because paying supplier invoices is a job every business has, the manual last step, logging into a portal and keying in a payment, is pure friction, and the pilot shows the exact shape that makes handing it to an agent safe: a human approves first, the agent is named and authenticated, credentials are tokenized so no logins are shared, the payment is bound to one invoice and one approved amount, and both sides can see the authorization and the completion.
